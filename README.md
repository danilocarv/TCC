## 📌 Sobre o Projeto

Este projeto desenvolve uma solução integrada de Ciência de Dados e Aprendizado de Máquina aplicada ao **Vehicle Energy Dataset (VED)** para veículos 100% elétricos (Nissan Leaf 2013).

O desenvolvimento está organizado em duas fases principais:
1. **Fase 1 (Classificação de Perfis de Condução)**: Extração de métricas de comportamento do condutor e agrupamento não supervisionado (K-Means) em perfis (*Econômico*, *Moderado*, *Agressivo*), com módulo interativo de teste.
2. **Fase 2 (Predição de Consumo Energético)**: Modelagem supervisionada de regressão (Linear, Random Forest e Redes Neurais Artificiais / MLP) a partir de dados de telemetria e trajetórias GPS com altimetria/declividade da via.
